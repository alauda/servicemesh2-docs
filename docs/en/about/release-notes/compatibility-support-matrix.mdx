# Compatibility and support matrix

The following table shows the compatibility and support matrix between Alauda Service Mesh and the Alauda Container Platform versions.

| Alauda Service Mesh | Istio | Alauda Build of Kiali | Alauda Container Platform |
|---------------------|-------|-----------------------|---------------------------|
| v2.1                | 1.28  | v2.22                 | v4.1.1+, v4.2, v4.3       |
| v2.0                | 1.26  | v2.11                 | v4.1.1+, v4.2, v4.3       |

:::note
- The Alauda Service Mesh v2 Operator bundles earlier Istio releases so that you can update an existing control plane, but only the Istio version listed in the table is supported for each Alauda Service Mesh version. See [Understanding Service Mesh and Istio versions](../../updating/update-mesh/index.mdx).
- Alauda Build of Kiali is delivered by the Kiali Operator, which is installed separately from the Alauda Service Mesh v2 Operator, so the Kiali version must match the version listed in the table.
- The table lists minor versions. For the exact patch versions of each release, see the [Release Notes](./index.mdx).
:::
