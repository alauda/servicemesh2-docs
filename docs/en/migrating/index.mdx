# Migrating from Alauda Service Mesh v1

Migrate a running Alauda Service Mesh v1 mesh to Alauda Service Mesh v2 while application traffic keeps flowing. Both control planes run side by side until every workload and gateway is served by Mesh v2, and Mesh v1 is then removed by hand.
