# Quick Start

This documentation provides the end-to-end paths for bringing up a complete Alauda Service Mesh v2 environment — mesh, sample application, observability stack — and for tearing it down again.

Each quick start lists only the operations involved and links to the document that describes each one. Follow the documents in the listed order.

Choose the path that matches the data plane you want to run:

- **Sidecar mode** — Every meshed workload runs its own Envoy sidecar proxy. See [Sidecar Mode Quick Start](./sidecar-mode.mdx).
- **Ambient mode** — A per-node ZTunnel proxy provides L4 features, with optional waypoint proxies for L7. See [Ambient Mode Quick Start](./ambient-mode.mdx).

:::note
The two modes are not validated for coexistence on the same cluster. Use a dedicated cluster for each quick start.
:::
